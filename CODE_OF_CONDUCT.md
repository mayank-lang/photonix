# Code of Conduct

photonix adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. Its full text is incorporated here by reference.

In short, we pledge to make participation in this project a harassment-free
experience for everyone. We expect participants to be respectful and
constructive and to stay focused on the work. Harassment, personal attacks and
publishing others' private information are not acceptable.

## Scope

The code applies in all project spaces: issues, pull requests, discussions,
reviews and any other channel where someone represents the project.

## Reporting and enforcement

Report unacceptable behaviour privately to the project maintainer,
[@mayank-lang](https://github.com/mayank-lang) on GitHub. Reports are reviewed
promptly and kept confidential. Enforcement follows the Contributor Covenant 2.1
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction, warning, temporary ban and permanent ban.
